Clinic Management Information System
- A responsive web-based healthcare management application built to streamline daily clinic operations, manage patient records, and enforce role-based access security.

__Key Features__

- Role-Based Access Control (RBAC): Customized access privileges and administrative views for Admins, Doctors, Nurses, and Employees to preserve patient privacy and data security.

- Patient & Clinical Data Management: Centralized recording, retrieval, and updating of medical histories and patient profiles.

- Workflow & Scheduling: Streamlined daily appointment booking and operational administrative workflows.

- Relational Database Design: Efficient SQL queries and database schemas for fast and secure data transactions.

__Tech Stack__

- Frontend: HTML, CSS, JavaScript

- Backend: PHP

- Database: MySQL / Relational SQL

- Environment: EasyPHP / WAMP / XAMPP

__Installation & Setup__

1-Clone the Repository:

git clone https://github.com/khaledelzein1/Clinic-management-information-system.git


2-Web Server Setup:
Move the cloned project folder into your web server root directory (e.g., htdocs or www).

3-Database Configuration:

Import the database .sql script using phpMyAdmin or your MySQL client.

Update database credentials in your configuration file if necessary.

4-Launch:
Access the application via http://localhost/Clinic-management-information-system.
